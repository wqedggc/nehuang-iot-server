# 涅凰智农 IoT 云平台 — 产品说明书

> 版本：v0.3.0 | 更新：2026-06-29

---

## 一、产品概述

涅凰智农 IoT 云平台是一个面向农业物联网场景的 SaaS 平台，提供设备接入、数据采集、远程监控、设备绑定管理等功能。平台分为**管理端**（管理员视角）和 **C 端**（农户/小程序视角）两个入口。

**技术架构**：Go 服务端 + MySQL，前端通过 `//go:embed` 嵌入单一二进制，部署简单。

**访问地址**：`http://43.143.208.153:8080`

## 三、管理端功能

### 3.1 Dashboard

入口：登录后首页

**5 类统计数据**，支持时间范围切换（1天/3天/7天/30天）：

| 类别 | 统计维度 |
|------|---------|
| 用户统计 | 总用户数、管理员数、农户数、今日新增、活跃用户 |
| 设备规模 | 网关数、采集执行器数、功能点数、在线/离线设备数 |
| 设备状态 | 各功能类型数量、各运行模式分布 |
| 数据上报 | 事件总数、心跳数、遥测数、注册事件、控制结果 |
| 控制统计 | 下发命令数、成功/失败/超时数、待处理数 |

### 3.2 用户管理

- 查看全部用户列表
- 按关键词搜索农户
- 查看农户详情（含绑定设备数）
- 编辑农户资料（手机号、地址、备注）

### 3.3 设备管理

- **设备树**：Gateway → 采集执行器 → 功能点 三层结构，展示设备层级关系
- **功能点搜索**：按关键词搜索、按绑定状态过滤（已绑定/未绑定）
- **采集执行器列表**：查看所有采集执行器节点

### 3.4 绑定管理

- 查看所有绑定关系列表
- **创建设备绑定**：选择农户 → 搜索功能点 → 一键绑定
- 查看指定农户的绑定设备
- 解绑设备（软删除）

### 3.5 控制日志

- 查看控制命令下发记录
- 查看原始设备事件日志

## 四、C 端（农户端）功能

### 4.1 设备列表

- 展示当前农户绑定的所有设备
- 显示设备名称、功能类型、实时数值、运行状态

### 4.2 设备详情

- **实时数据**：功能点实时值、状态、运行模式
- **历史曲线**：传感器时序数据（24小时范围）

### 4.3 个人中心

- 查看个人资料（昵称、手机号、地址）
- 编辑个人资料
- 版本号展示

### 4.4 设备控制（开发中）

- API 接口已就绪，硬件协议对接后即可下发控制指令

## 五、核心业务概念

### 5.1 设备层级

```
云边网关（FP_xxx）
  └── 采集执行器（E220/485/TTL，由 gateway_id + 频段 + 设备ID 唯一标识）
        └── 功能点（具体传感器/执行器）
```

### 5.2 功能类型

| 编号 | 类型 | 说明 |
|------|------|------|
| 1 | 温度 | 温度传感器 |
| 2 | 墒情 | 土壤湿度 |
| 3 | 限位 | 行程开关 |
| 4 | 水泵 | 水泵控制 |
| 5 | 风机 | 风机控制 |
| 6 | 继电器 | 通用继电器 |

### 5.3 绑定关系

- 管理员在管理端将**农户**与**功能点**建立绑定
- 绑定后农户可在 C 端查看该设备的实时数据和历史曲线
- 解绑为软删除，保留历史记录

### 5.4 设备事件

| 事件类型 | 说明 |
|---------|------|
| register | 设备注册上线 |
| heartbeat | 心跳包（定期上报） |
| telemetry | 遥测数据（温度/湿度/状态等） |
| control_result | 控制命令执行结果 |

### 5.5 控制命令生命周期

```
created → sent → ack → succeeded / failed / timeout
```

## 六、技术特性

| 特性 | 说明 |
|------|------|
| 单一二进制 | Go 编译为单个可执行文件，含嵌入式前端 |
| 纯标准库 | 无框架依赖（net/http + database/sql） |
| JWT 双受众 | admin token（24h）和 mini token（72h）通过 aud 隔离 |
| 雪花 ID | 自研 Snowflake 生成器，所有 ID 序列化为字符串 |
| 三模式 API 层 | 前端支持 real/mock/offline 切换 |
| Mock 设备脚本 | `mock_device_events.sh` 可模拟设备数据上报 |

## 八、常见问题

**Q: 管理端 Dashboard 显示心跳成功率为 0%？**
A: 心跳统计功能依赖 telemetry 系统，当前为 TODO 状态，后续完善。

**Q: C 端点击"控制"按钮没有反应？**
A: 设备控制链路尚未对接硬件协议，API 接口已占位，前端显示"功能开发中"。

**Q: 如何切换前端 API 模式？**
A: 修改 `web/static/mock/mock-api.js` 中的 `MODE` 变量：`'real'`（真实 API）、`'mock'`（本地 Mock）、`'offline'`（离线）。

**Q: 如何新增农户？**
A: 当前农户通过 C 端模拟登录自动创建，或在管理端手动添加（开发中）。
